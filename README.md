# STAT6 website

Marketing site for STAT6: custom software, AI agents, AI automation and integration, and websites. STAT6 BMS waitlist included.

## Stack
React 18, Vite 6, Tailwind CSS 4, Motion, Lenis smooth scroll, Phosphor icons.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
Output goes to `dist/`.

## Before launch
- Replace placeholder clients, quotes, portraits and figures with real ones (with permission).
- Connect the contact and waitlist forms (marked `TODO` in `src/components/Sections.jsx` and `src/components/Hero.jsx`).
- Review `public/privacy.html` and `public/terms.html`.
- Add a 1200×630 social share image.
